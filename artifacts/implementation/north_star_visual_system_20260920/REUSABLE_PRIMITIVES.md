# Reusable Primitive Specification — Candidate North Star System

## Canonical candidate primitives

| Primitive | Governed input | First-read job | Exact evidence | Interaction | Forbidden behavior |
| --- | --- | --- | --- | --- | --- |
| Primary Insight Stage | upstream insight / decision state | establish dominant truth | exact metric/action state adjacent | primary action or focus | creating a new recommendation |
| Identity Header | canonical player/team/owner fields | establish who/what the page is about | role/state/age where available | focus/select | invented logos or personality |
| Rank Band | league-relative rank + exact value/index | show place vs peers | rank/population + exact index | reveal peers/details | hidden score |
| Delta Band / Shift | same-unit before/after delta | show direction and size | exact signed delta | compare scenarios | cross-unit weighting |
| Probability Ring / Shift | governed probability level/change | show likelihood or movement | exact probability + horizon | reveal distribution if present | fabricated confidence |
| Risk Band | governed fragility/exposure diagnostic | show vulnerability | exact diagnostic | open replacement detail | arbitrary safe/danger thresholds |
| Trajectory Strip | historical/horizon/season observations | show direction through time | actual observed points | scrub/tap milestones | fake interpolation |
| Distribution | governed quantiles/moments/scenarios | show uncertainty | mean/median/interval | inspect tails | drawing uncertainty from a point estimate |
| Atlas / Heat Cell | governed league coordinate | reveal structure spatially | exact value/rank on focus | filter/focus/drill | composite power score |
| Package Bridge | canonical sent/received assets | show exchange identity | separate Value/Decision lanes | open asset or decision detail | blending Value into disposition |
| Story Rail | already-governed primary upside/risk/action | compress interpretation | source evidence underneath | drill into one lane | presentation-created conclusion |
| Evidence Drawer | provenance/methods/tables | preserve depth | full exact detail | expand/collapse | hiding unavailable evidence |

## Visual semantics

- action / focus: blue;
- favorable signed change: green;
- unfavorable signed change: red;
- warning / incomplete state: amber;
- unavailable: muted/low-emphasis.

These are presentation semantics. They do not replace upstream materiality classifications.

## Composition rule

A primitive may be card-shaped only when the object itself is bounded and interactive. Default page grouping should use type, whitespace, alignment and rules before borders, shadows and rounded containers.
