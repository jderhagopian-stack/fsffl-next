## Unsupported mockup concepts deliberately excluded

The approved eight-screen mockup is not treated as a model specification. The bounded reference does **not** introduce:
- Team Grade;
- generic Fit score;
- owner-adjusted Value;
- stable owner-preference label;
- numeric acceptance probability;
- fabricated Behavioral certainty;
- visual recommendation inferred from bars;
- composite/master score;
- unavailable uncertainty distribution.

Where the mockup uses a persuasive visual role, this implementation uses the nearest governed truth or an explicit unknown/unavailable state.
