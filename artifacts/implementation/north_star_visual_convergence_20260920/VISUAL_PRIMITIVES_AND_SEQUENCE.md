# FSFFL NEXT — Shared Visual/Product Primitive Inventory and Redesign Sequence

Date: 2026-09-20

## Primitive inventory

### Already present, but mostly surface-specific
- dominant insight/action hero modules;
- position-strength tracks in Franchise;
- league edge cells / rank matrix;
- status/risk/action color semantics;
- progressive evidence/details disclosure;
- side-by-side trade package presentation;
- mobile breakpoints and bottom navigation.

### Missing as reusable product grammar
1. **Identity Header** — consistent franchise / owner / player identity block with name, role/context and one governed secondary fact. It must not invent logos/personality.
2. **Rank Band** — league-relative position for strength/value/age/pick evidence with rank, benchmark and exact value visible together.
3. **Delta Band** — signed before/after or scenario-change visualization centered on zero, always paired with the exact returned number.
4. **Probability Shift** — compact baseline/scenario or signed probability-change treatment; never a gauge without clear denominator/horizon.
5. **Risk Band** — fragility/replacement-exposure visual with exact diagnostic and explicit meaning.
6. **Trajectory Strip** — age / draft capital / horizon evidence over time without long row lists.
7. **Compact Distribution** — uncertainty/range primitive for governed distributions when available.
8. **Opportunity Summary** — package + need/fit + consequence + authority state in one scan-first unit.
9. **Atlas Cell / Heat Map** — consistent league-map grammar for position, age, capital and depth without generic tables.
10. **Evidence Drawer** — consistent secondary methods/provenance disclosure.
11. **Mobile Scan Stack** — explicit mobile ordering and horizontal-scroll/carousel rules so desktop density is not merely compressed.
12. **Primary Insight** — reusable dominant takeaway + one action module.

Every primitive must visualize already-governed truth and preserve exact values nearby. None may create a recommendation, master score, acceptance probability or new model threshold.

## Re-ranked convergence sequence

### 1. System primitive + Trade consequence visualization — implement now
Establish the first reusable shared primitive, **Delta Band**, and apply it to Trade Center competitive consequences. This visibly improves a high-value decision workflow and creates a reusable pattern for Scenarios, Home deltas and later historical comparisons.

Scope:
- shared visual-primitives stylesheet loaded globally;
- exact signed value remains primary and textual;
- zero-centered directional band adds scan speed;
- metric-specific display range is explicitly a visual cap only, never a model threshold;
- the result is labeled “change after trade”;
- mobile stacks intentionally;
- legacy/method evidence remains available underneath;
- no Decision/Simulation/Value logic changes.

### 2. League atlas convergence
Apply shared Rank Band / Atlas Cell / trajectory primitives to competitive lanes, age, picks and depth. Preserve exact data in drill-down.

### 3. Market opportunity visual grammar
Unify need → package → consequence → authority into a reusable Opportunity Summary; reduce prose and duplicated cards.

### 4. Franchise identity / trajectory refinement
Add stronger player/franchise identity and compact age/draft-capital trajectory while retaining current strong diagnosis structure.

### 5. Owner identity / tendency refinement
Build on merged PR #158 with shared identity and tendency/distribution primitives; do not fabricate preference or acceptance.

### 6. Home visual freshness once evidence exists
Use the same primitives for change/activity only after the governed previous-distinct-State contract exists. Current Home can still receive visual compression without inventing “since last visit.”
