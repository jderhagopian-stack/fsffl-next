## Executive conclusion

The study does **not** support a broad event-rich H1-H3 adjustment layer.

It does support a narrower Forecast contract:

1. football-state changes trigger Forecast reevaluation, not direct Intrinsic penalties;
2. H1 must separate remaining-season availability from conditional active production;
3. when governed current ROS is authoritative, ROS owns the integrated H1 update and event state is explanation/provenance only — no second haircut;
4. when ROS authority is absent, no generic injury/transaction multiplier is justified; only separately governed direct availability/eligibility evidence may alter the availability component;
5. temporary injury does not receive a generic H2/H3 penalty;
6. **release/cut at H3** is the one event-specific cohort that clears the frozen gate, and only supports a coarse attachment/survival-risk state, not a position-specific cardinal haircut.

## Why the broad paths failed

The frozen gate required at least one core metric to improve >=2%, no other core metric to degrade >5%, position state-Brier safety, and stability across holdouts.

- availability/participation: point MAE improves only **0.34%** — below threshold;
- all-event: point MAE improves **2.60%**, but persistence Brier worsens **7.09%** — fails.

### H2
- organizational: point MAE improves **1.89%**, while persistence Brier worsens **13.69%** — fails;
- availability/participation: point MAE improves only **0.43%** — below threshold;
- all-event: point MAE improves **2.31%**, but persistence Brier worsens **14.64%** — fails.

### H3
No broad family reaches a qualifying improvement:
- organizational worsens persistence/state/point MAE;
- availability/participation improves point MAE only **0.66%** while Brier metrics worsen;
- all-event is essentially flat on points and worse on both Brier metrics.

Therefore the broad event layer is not an accepted updater at any H1-H3 horizon.

## Injury episodes — 4,793

The episode evidence strongly supports **decomposition**, not a causal penalty.

Availability changes materially with contemporaneous severity:
- limited/questionable: mean remaining participation **80.2%**;
- doubtful/out: **42.7%**;
- reserve/IR/PUP/NFI: **28.1%**.

Post-return role is a different quantity:
- median opportunity ratio is **0.955 / 0.980 / 0.837** across those classes.

Conditional production is also distinct:
- median post-return PPG ratio is **0.879 / 0.877 / 0.852**.

Recurrence is distinct again:
- **49.6% / 28.0% / 25.9%** under the study's repeated-injury-limited definition.

None of these descriptive ratios is a causal coefficient. The OOT injury-state layer fails the promotion gate at H1, H2 and H3, including non-IR and reserve cohorts.

Result:
- **remaining-season availability:** separate component;
- **conditional healthy production:** no generic injury haircut;
- **post-return role:** no generic multiplier;
- **recurrence:** provenance/risk state only today;
- **H2/H3 durable injury effect:** no generic adjustment.

## Non-injury events — 7,603

Observed promotion/demotion events show the expected immediate role movement because they are defined from opportunity changes:
- promotion median post-opportunity ratio **1.406**, post-PPG **1.345**;
- demotion **0.667 / 0.661**.

Those are not causal long-run multipliers. They should trigger reevaluation of current role/projections.

Team changes are heterogeneous:
- overall median opportunity ratio **0.956**, PPG ratio **1.062**;
- QB, RB, WR and TE move differently.
No generic NFL-trade bump or penalty is supported.

Release/cut is the narrow exception:
- H1/H2 point-MAE gains are accompanied by large persistence-calibration degradation and fail the gate;
- H3 continuity evidence clears the frozen event-family gate on **62** OOT rows across four holdouts:
  - persistence-Brier improvement **2.61%**;
  - state-Brier improvement **0.70%**;
  - point MAE worsens **1.93%**, within the 5% tolerance;
  - persistence direction improves in all four holdouts.
No position subgroup reaches n>=30, so this is **coarse H3 survival/attachment evidence only**.

Suspension/exempt has only 25 historical events and retirement one; neither supports a fitted coefficient.
