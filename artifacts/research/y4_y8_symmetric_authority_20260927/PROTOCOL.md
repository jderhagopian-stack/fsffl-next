## Symmetric scientific rule

For each cell and policy pair:

- report point-error MAE and RMSE/MSE;
- report bias;
- report rank ordering / Spearman where support permits;
- report top-tail error;
- report empirical interval coverage where the policy emitted calibrated intervals;
- report origin-by-origin direction;
- compute paired dependence-aware uncertainty from exact common rows using source-origin × player clustering where identifiers permit.

Classification:
- **supported difference** — the paired clustered interval excludes zero on a primary dimension and chronology is not contradicted materially;
- **directional but uncertain** — central direction exists but interval includes zero / chronology is thin;
- **practical tie** — primary differences are small, uncertain and no material safety/calibration advantage resolves them;
- **tradeoff** — different policies materially lead on different primary dimensions;
- **uncomparable** — exact common evidence for that dimension cannot be recovered.

No “challenger must improve by X% to replace the incumbent” rule is used.

## Primary dimensions

Long-horizon production authority is multi-objective because Intrinsic is sensitive to the upper production tail.

Primary:
1. RMSE;
2. top-tail RMSE;
3. MAE;
4. rank/Spearman;
5. absolute bias.

A policy is not granted universal authority because it wins only MAE if it materially compresses the upper tail, and it is not granted universal authority because it wins only tail/RMSE while degrading typical error materially.

Coverage/calibration is a safety dimension, not a post-hoc tie-break invented after results.
