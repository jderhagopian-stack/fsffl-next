# Stage C Structural-Risk Eligibility Freeze

This checkpoint is deliberately persisted before S1/S2 fitting or outcome inspection.

The only eligible structural-risk family is continuous late depth-chart role / starting-job security erosion.

Permitted scope: QB Y2/Y3 and WR Y2/Y3. RB and TE receive no structural-risk adjustment. The future Forecast repair does not alter governed Y1.

Representation uses three continuous source-time quantities from weekly depth charts: (1) mean depth rank over the final four available source-season observations, (2) starter share over those same final four observations, and (3) late-half minus early-half starter share. No binary threshold is permitted.

Missing depth-chart evidence produces no adjustment; missingness itself is not evidence of risk.

The mechanism may alter only existing future persistence / active-state / opportunity-state probability machinery. Conditional-production magnitude is not directly reduced by the Stage-C signal.

Coefficients, if estimable, must be learned only in the existing chronological Forecast framework using training-fold-only transformations and existing governed regularization/bounds. No current-board tuning, named-player calibration, threshold search, broad hyperparameter search, or target-period hindsight.

S1 is B2a unchanged on conditional production plus this exact structural-risk machinery. S2 is allowed only if an already-developed richer conditional-production component can be paired with the identical machinery without a new methodological choice.

Untouched holdout and the 335-player current board remain sealed for selection.
