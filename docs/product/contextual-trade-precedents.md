# Contextual trade precedents

Opportunities, Trade Center and counteroffers consume the same admitted historical
examples through the existing owner-history reader. This extends the accepted
completed-trade evidence lane, not Forecast, Value, Team Utility or Decision economics.

## Time and context

Provider league year, action completion date, NFL campaign and record season are
separate fields. Calendar-backed offseason trades retain the upcoming campaign;
last year's record is background, never the owner's current in-season state.
Completed regular-season records say which season ended. Partial older records keep
the year and through-week. Missing results never establish offseason. Unavailable
calendars and dates within the existing two-day completion bound remain unknown.

The compiler carries typed asset directions and positions only from dated production
evidence. Today's player metadata is not retroactively assigned to a historical
trade. Retained players establish roster membership, not surplus, lineup strength,
expendability or a preferred competitive timeline.

## Shared tool use

The shared reader finds actual examples with matching player/pick flow or known
position direction. A stronger contextual match additionally requires a regular-season
record from that trade's actual football campaign, the same completed week, and the
same winning/losing/even record category in the current canonical matchup evidence.
Unknown or conflicting circumstances never become a contextual match.

Once a structured casebook is available, generic activity counts remain explanatory;
they do not substitute for an absent relevant precedent in search or counter ordering.
Opportunity selection prefers relevant precedents only after existing economic,
objective, package-size and diversity gates. Counter search orders its history lane
by the same categories while preserving every alternative and existing repair lanes.
All candidates still pass the existing bilateral evaluation. Trade explanations lead
with a bounded dated example. No historical count changes a valuation, recommendation
truth, acceptance probability or declared owner preference. No sample of rejected
offers or imagined historical forecast is introduced.

## Coverage and resource bounds

Retain at most 64 validated cases per owner in the existing profile JSON, replacing
the 12-example research window. This covers all 291 participant sides in the admitted
144-trade cohort. The default UI still shows three examples before expansion. The
reader returns at most two relevant precedents per side; the consumer shows one.
Source events and the immutable full casebook remain intact.

Pure request-local matching uses cached exact-State profiles and canonical matchup
results. No request fetches sources, fits a model, reads another database table or
rebuilds history. The larger bounded cohort has an explicit 1.5 MB aggregate profile
JSON regression budget; measure actual size and matching latency before release.
Existing persistence and owned background materialization remain the only publishers.

Legacy case fields and immutable bundles remain readable. Artifact fingerprints
validate the original stored payload before optional schema defaults are applied.
A structured v2 representation can replace v1 at the same original source observation
time; publication must not undo the upgrade or rewrite source clocks. Derived
artifact computation time remains separate from observation time.

Acceptance includes offseason/container-year regressions, missing calendars, future
and foreign evidence, economic precedence, counter completeness, shared narrative,
real-source coverage, bounded work and all-owner mobile behavior. Source replay is
not proof that a hypothetical exchange is currently legal or economically beneficial;
current production outcomes require the existing roster and model evaluation.

## Initial pinned-source validation

The source cohort contains 206 offseason and 83 regular-season participant sides;
two boundary dates remain unknown. For 208 observations, the recorded campaign is
not the trade's football campaign and must remain background. The shared reader
finds directional precedents for 246 recorded-exchange hypotheses across all 12
owners; 35 participant sides lack both economic sides in the supported player/pick
representation, and ten remaining hypotheses do not establish a material match.
These are coverage facts, not current-trade quality or owner-acceptance estimates.

The local shared-reader check processed 640 hypotheses in 0.084 seconds using the
full 291-case cohort. Instrumented background bundle decode/attachment measured a
1.64-second median and about 7.8 MB additional traced allocation over three runs.
These are local isolated measurements, not hosted request or full-refresh metrics.
The prepared bundle is about 752 KB, and the 12-profile JSON about 763 KB. No new
provider calls, fitted models, database adapters, services or recurring costs.
