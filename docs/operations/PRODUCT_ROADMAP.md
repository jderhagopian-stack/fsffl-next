# FSFFL NEXT — Product Roadmap

1. Forecast Research: K/DST architecture + new-league bootstrap.
2. Governed implementation from accepted research contract.
3. Resume and complete new-league 7/7 lifecycle acceptance.
4. Physical-iPhone Market acceptance.
5. Home × Franchise redundancy/information-hierarchy audit.
6. Trade Discovery architecture review.
7. Trade Center work only after the discovery/search order of operations is settled.

## Trade Discovery principle
Simulation should evaluate shortlisted trades, not perform broad discovery.

Target sequence:
`League State → needs/opportunities → candidate assets/partners → broad cheap package generation → governed filtering → bilateral plausibility → opportunity frontier → targeted simulation → deeper decision analysis`

Simulation is a microscope, not the searchlight.

## League-agnostic validation
“League-agnostic” is a target, not yet a fully proven property. Future validation must deliberately exercise configurations unlike the original FSFFL league, including K/DST where supported, different roster structures, and scoring differences.
