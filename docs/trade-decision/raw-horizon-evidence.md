# Raw horizon evidence for selected trades

The first strategic-discovery foundation adds `horizon_asset_economics` to hosted
Trade Center analysis and successful Simulation responses. It supplements the
existing outputs; it does not change current dispositions, claim team-specific
utility, compute a market discount or expose a redesigned UI.

The adapter consumes an existing completed Career contract from its bounded
producer-owned memory record. The existing memory-only publication proof checks
the exact user/league/State/managed team/generation and dependency fingerprint.
No record restoration, database payload read, model fit, Forecast acquisition,
Shapley run, new cache or additional work coordinator is introduced. Released,
ambiguous, unpublished or incompatible evidence remains unavailable. Failure of
this optional channel preserves existing market, roster and Simulation results.

For selected players, the adapter reuses canonical annual-component validation
and Value's accepted 3-Year discount; Career retains its accepted undiscounted
Y1–Y7 + Y8+ aggregate. Only selected rows are projected for validation; original
source-cohort and dependency identity are preserved. No new coalition game is
calculated. The two horizons receive distinct native unit/reference identities.
Neither display indexes nor Market scores enter them.

Existing NEXT-5 package/economic-net contracts bind received-minus-sent means
within each native horizon. Positive, zero and signed negative quantities remain
unchanged. Missing pick/player/FAAB evidence is carried by side and flow; a partial
package cannot expose a fabricated complete net. Package uncertainty remains
unavailable because covariance and a whole-Career outcome interval are not
provided by these authorities. Internal typed adapters pass only the existing
point reference into mean-only aggregation; they do not assert zero economic
uncertainty. Source model uncertainty remains separate. Source scoring-coordinate limitations,
ignored residual-rule qualifications and selected-player input assumptions remain
explicit in the evidence packet. Complete mean arithmetic is not a claim of
unqualified model accuracy.

The result explicitly says `evidence_only_no_disposition_change` and identifies
these as raw asset-contribution ledgers. Both-team lineup/competitive effects,
required-cut accounting, horizon-aware objective interpretation and final
recommendation are distinct Decision/Team Utility responsibilities. This tranche
does not promote incomplete evidence to a recommendation or claim full long-term
strategy integration is finished.

Search posture responses separately expose `priority_resolution`: automatic
competitive-state hypothesis, explicit user search instruction, or unknown-state
balanced fallback. Existing posture resolution and search order are unchanged.
The current v1 metadata explicitly says owner behavior was not used and no durable
owner preference is claimed. Richer inferred priorities and multiple explicit
constraints remain staged development under the strategic discovery roadmap.

Focused regressions cover source/generation/team/time mismatch, compatible raw
horizons, missing assets, zero/negative/nonfinite contributions, source immutability,
no hidden source work, ownership-before-evidence ordering, optional-channel
failure isolation and automatic/user-directed mode semantics. Hosted/browser and
real-league economic usefulness require their own targeted acceptance evidence.

The next backend tranche adds optional `roster_adjusted` evidence inside each
horizon using the existing authoritative required-cut resolution. Original raw
sent/received totals remain unchanged. See [objective assessment](objective-assessment.md)
for request-scoped goals, both-team directional interpretation and limitations.

Bounded discovery separates the same reader from transaction binding: one
publication-validated, request-local native-value projection can serve many
packages. An immutable snapshot weak reference avoids repeating full-State
serialization and prevents cross-snapshot reuse without retaining the State or
source contract. Each package retains exact generation/source/horizon identity;
this introduces no model recalculation or durable cache.
