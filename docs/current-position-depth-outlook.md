# Current Position & Depth outlook authority

Current lineup strength consumes typed Forecast observations prepared by
`forecast.season_comparison.build_participation_adjusted_outlook`. The player-card
comparison formats the same preparation into its separate presentation packet.
Current does not consume card JSON or reconstruct missing projections itself.

Preparation retains the accepted source selection, first-party fumbles completion,
participation exceptions, exact completed-week boundary and actuals-plus-ROS
composition. Single-source inputs and assumed-zero ROS inputs carry their basis,
confidence and provenance into Current player evidence. Genuine incomplete inputs
remain unavailable. No scoring, Intrinsic economics or reference anchors change.

Current v3 preserves configured lineup optimization and slot attribution. A WR
column requiring three starters remains unavailable for all-team ranking if any
team cannot fill those slots with accepted observations. FLEX and SUPERFLEX remain
separate assignments; bench, IR and taxi evidence does not automatically enter a
slot numerator.

The preparation still runs fresh under the existing presentation-promotion owner.
State alone is not a safe cache key: ROS evidence can advance within the same State.
This adds no worker, lifecycle controller, raw-cohort cache or database path.
Accepted single-source completion can add predictor/acquisition work for eligible
players. Hosted refresh runtime and peak memory therefore need measurement on the
next ordinary refresh; local fixture timing is not a production resource estimate.

Regression coverage exercises three mandatory WR slots, single-source fumbles
completion, sparse-production and IR assumptions, genuine missing-fumbles failure,
writer-only history compatibility and the real team-views API. Fixture injection
controls provider acquisition and fumbles predictor output; scoring, composition,
participation decisions and lineup/ranking execute the production implementations.
The card comparison retains v5 and its existing output contract.
